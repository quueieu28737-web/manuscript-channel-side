## 下一步重新评估：先确认测量对象，再设计同边界对照

CachePrune 和 SafeKV 属于服务层 KV 缓存路径；WRA 的诱饵属于 agent 网络轨迹。直接把三者放进一张统一数值排行榜会混合不同的目标、观察者和工作负载。可采用共享的保护、功能、成本报告框架，分别设立缓存路径和 agent 路径；只有匹配的观察边界和任务才能共享效应对比。

1. 对每种防御固定代码版本、模型权重、配置、许可、硬件、任务和观察者；确定是否能取得原作者实现及完整依赖。CachePrune [原论文](https://arxiv.org/abs/2605.23640)和 SafeKV [原论文](https://arxiv.org/abs/2508.08438) 的复现代码在本次检索中尚未定位到可直接运行的官方实现；不能把类似机制默认为原实现。WRA [作者仓库](https://github.com/umass-aisec/wra) 提供代码和数据说明，仍须检查版本、许可与数据。
2. 在缓存路径比较共享、租户隔离和可取得的选择性隔离实现；同一请求集和负载上测目标推断、质量、首 token 时间、吞吐和资源。将原实现与独立重实现分开标注。
3. 在 agent 路径比较原轨迹与真实可执行的诱饵策略；同一任务上测网络可观测性、任务成功、调用/字节和在线耗时。排除无授权的真实账户或第三方状态操作。
4. 在接触测试结果前冻结攻击目标、采样单位、训练/测试隔离、攻击者重训练、统计方法和失败处理；报告按独立用户或任务簇的区间、模型及数据许可。仅完成一个路径时，单独报告它的结果，不称为跨三种防御的统一结论。

本机检测到一张 16 GB RTX 4090 Laptop GPU，可用于评估轻量级开放模型；它不能自动满足原论文的大规模服务配置。具体运行能力、源码可获得性和数据许可尚待核实。以上为研究方案，不是已完成实验。
