## 新的核心叙事（一句话）

防御证据能否在 LLM/Agent 部署之间复用，取决于三条边界：接收视图、受影响状态、攻击者与工作负载。其中"受影响状态"在 WF 和对抗 ML 评估传统里没有对应物（这是本文真正的新增点）；"攻击者拟合"是既有原则（本文只做量化，不认领）。报告卡把这三条边界逐条落到"每个声明"的判定上：supported / incompatible / unresolved（并给出缺失的测量项）。两个案例分别显示忽略其中一条边界会让结论反转。
