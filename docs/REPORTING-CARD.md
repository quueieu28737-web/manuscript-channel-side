# Defense evidence reuse card

Copy one card for one source configuration and one proposed deployment. Unknown is a valid answer. Add a source version and section/table/figure locator to every evidence field.

| Field | Source result and locator | Proposed deployment / change |
|---|---|---|
| Receiver and target | Hidden property, signal, permissions, public outputs | |
| Intervention | Primitive, execution mode, trust and state boundary | |
| Attacker and test | Fit/calibration, defended testing, units and sample population | |
| Function | Component quality or workflow outcome at the same configuration | |
| Cost | Resource, units, baseline, denominator and included operations | |
| Extension | Workload/model/hardware/network holdout and calibration provenance | |
