\title{SoK: Reusing Defense Evidence in LLM and Agent Side Channels}
\author{}

\begin{document}
\maketitle

\begin{abstract}
Choosing a side-channel defense requires knowing which reported outcomes apply to the intended deployment. This SoK organizes that evidence for LLM serving and agent systems. We map 82 study families and examine 39 result records, including 33 mitigation records from 20 families. A taxonomy of changes to the observed signal, executed intervention and evaluation setting guides three practical tasks: compare like outcomes, identify protection, utility and cost measured at the same configuration, and specify what a new deployment still needs to measure. A running cache-reuse example shows the distinction: Early Bird's prefix-recovery result and semantic-cache overhead concern different mechanisms, whereas CachePrune links two recovery targets to one quality-and-cost package. We publish the record identities and query memberships needed to reconstruct these decisions. Pair counts are an inventory conditioned on record granularity, not an estimate of deficient research. Worked applications retain useful source results while separating incompatible cost or utility claims. The resulting evidence atlas and reporting template support source-scoped candidate selection and explicit measurement plans.
\end{abstract}
