\section{Three Reuse Boundaries}\label{sec:boundaries}\label{sec:corpus-map}
This section states each boundary, shows it in published LLM and agent defenses, and ends with the reporting rule it implies. The source examples were chosen because they exhibit the boundary clearly; Appendix~\ref{app:sources} describes how they were collected.

\subsection{Receiving view}\label{sec:receiving-view}
A protection result covers the signal that was measured, at the point where it was measured. It does not cover a signal produced later from the same content.

NetEcho makes this concrete \cite{netecho2025}. Packet-size shaping on the upstream API link changes the observed sizes, but a plaintext-aware frontend then regroups the decoded tokens and emits a fresh size trace, reopening the channel that the upstream shaping closed. The same issue arises within a single interface. SICC shows that once message content is authorized for release, its length and structure can still support inference, and isolates that form-only channel \cite[Table~3]{xu2026sicc}. DP-MemView protects attributes at its compliant semantic interface; a separate diagnostic that exposes an internal score reaches an attribute AUC of 0.976 \cite[RQ2]{dpmemview2026}. That number is not an attack on the compliant interface---it is a result for a different released view. A reuse decision that cites DP-MemView's privacy result must name which of the two views the deployment exposes.

\soktakeaway{Rule 1 (Receiving view)}{Bind each protection result to the final emitter and the exact fields it releases. If the deployment adds an emitter or releases another field, measure inference on that trace.}

\subsection{Affected state}\label{sec:affected-state}
Cover is the main defense against agent traffic analysis, and it comes in two kinds. WRA issues decoy research requests and returns only the real output to the user; the decoys' replies are discarded \cite{jeong2026wra}. AHB humanizes mobile GUI agents by executing additional GUI events \cite{zhu2026turing}. A reply that is discarded cannot affect the task. An event that executes can.

This difference matters because ``the response was discarded'' is a statement about content, while task success is a statement about state. A write whose response is ignored still commits; a sandbox, dry run or rollback limits that effect only within its own contract \cite{kubernetesdryrun,stripesandboxes,postgresrollback}, and some changes, such as sequence advances, survive rollback \cite{postgressequences}. Other agent defenses preserve narrower objects: UI-trace timestamp edits preserve action order \cite{uitraces2026}, and Dangol's protected captures preserve fixed message bodies \cite{dangol2026workflow}. Each supports its stated preservation claim, and none establishes task completion under added execution. Case~B (\S\ref{sec:case-b}) measures how large the difference between discarded and executed cover can be.

\soktakeaway{Rule 2 (Affected state)}{State whether cover is discarded, isolated or executed. A content-preservation witness supports only the preserved content; executed cover needs a task-outcome measurement that includes its state effects, quotas and failures.}

\subsection{Attacker and workload}\label{sec:attacker}\label{sec:evaluation}
A protection number depends on how the attacker was trained. A classifier fitted to undefended outputs and then tested on defended outputs measures distribution shift as much as protection; the relevant attacker is fitted on defended outputs \cite{tramer2020adaptive,juarez2014critical}. Case~A (\S\ref{sec:case-a}) shows the gap in an LLM streaming setting.

Workload changes raise a related question: what exactly was held out? Table~\ref{tab:r26-transfer-objects} separates three evidence objects that are often conflated. LLM-Fin, ArchSnoop and LeakyLMs show that \emph{attacks} generalize to unseen model variants or architectures \cite{nazari2024llmfin,weng2026archsnoop,majidi2026leakylms}. Time Will Tell instead evaluates one \emph{defended condition} on several models: a 60-word-explanation instruction changes mean attack success from 88.2\% to 61.9\% on GPT-4o, but from 79.3\% to 80.3\% on Gemma2-9b-IT \cite[VII-B]{timewilltell2024}. Whisper Leak reports mitigations per provider and model \cite[3.2,6]{whisperleak2025}. Such results are local to each model; they are not evidence that a defense calibrated on one model protects another. That third object, \emph{defense transfer}, requires holding a source calibration fixed and comparing it with one fitted locally on the target.

\subsection{Function and cost follow the configuration}\label{sec:cache-decisions}
The three boundaries also govern function and cost. A cost or quality number is reusable only for the configuration that produced it. Early Bird's approximately 6\,ms de-identification overhead was measured on a semantic-cache prototype with 1,000 Presidio sentences, while its token-recovery results (91.5\% at $K{=}1$, 49.0\% at $K{=}4$; v5 Table~VI) concern a minimum-shared-prefix rule \cite[V-A--B]{earlybird2025}. The overhead cannot price the prefix rule, and we did not locate a serving-cost or task-utility measurement for it. SpliceDefense reports a sub-1\% prefill cost for quantized chunk padding, a different component from the boundary-fusion mechanism whose timing residuals it reports \cite[VII-C, Table~II]{spliceleak2026}. Formal and hardware defenses keep their own boundaries: OTRO's DRAM-trace indistinguishability holds under its ORAM and pseudorandom-function assumptions and excludes computation timing \cite{lee2026otro}, and Palermo's near-zero mutual-information statistic concerns its stated stash/tree and timing variables under an external-memory observer, not prompt recovery \cite{ye2024palermo}. In each case the source supports its own claim; the error would lie in the join.
