\subsection{Workload, framework and paired interventions}\label{sec:live-study}
A LangGraph state graph~\cite{langchain2025langgraph} alternates model decisions and actual MCP tool calls. Every execution begins with the same support-queue instruction. The first tool response supplies one of six requested service actions: refund, address update, escalation, replacement shipment, cancellation or receipt. Tool responses contain service-specific supplementary records with randomized contents and counts. These schemas deliberately expose a testable category dependency; they do not sample its prevalence in deployed tools. Tasks require one to three independently assigned checks; a fixed random subset encounters one recoverable check failure. The framework exposes unfinished prerequisites before permitting all six business actions, leaving the action choice to the model. Applied fixture state and goal completion are recorded separately.

The plan assigns 312 task instances to 64 sessions per condition, with 0--10 arrivals per session. Labels are balanced over train/validation/test partitions while session compositions vary. The 32/8/24 session split contains 156/36/120 tasks. Test requests use four held-out phrasings per action. Empty sessions, missing classes and duplicate same-class tasks prevent class occupancy from being inferred from a fixed block composition. Live MCP background requests continue during idle periods.

Five conditions reuse each task's fixture and seed. \emph{Full} forwards the entire structured tool result to later model requests. \emph{Projected} forwards a fixed allowlist of task and prerequisite fields, dropping supplementary records after the unchanged response reaches the client. Both run serially with padded tool messages. \emph{Dedicated} and \emph{Shared} run four workers with separate or shared connections per service. \emph{Joint} additionally pads model requests and shapes model SSE frames under the shared policy. Incremental frame delivery can exceed its minimum schedule; this is measured, not treated as constant-time protection.

Qwen3:8B and Llama3.1:8B use fixed local weights. MCP Streamable HTTP and the model gateway use TLS~1.3/HTTP/2; the model gateway streams SSE. Packet capture observes encrypted sizes, timing, direction and physical connection grouping. Private tool logs and decrypted HTTP stream identifiers supply verification and ground truth only. The supplied-window analysis aggregates every visible connection within its window; continuous detection receives session boundaries and connection identities without task or private stream assignments.

The local cohort completed 3,120 executions and 13,680 model requests. Wire verification confirms overlapping model streams in 107 of 128 sessions in each shared condition, with up to four simultaneous requests on one connection. The remaining sessions include empty and single-task cases.

\subsection{Inference, localization and uncertainty}
Primary attacks are standardized logistic regression (LR) and the released 175-feature k-FP extractor~\cite{hayes2016kfp} with a 1,000-tree random forest. An aggregate random forest and temporal convolutional classifier provide additional attack families. Validation chooses hyperparameters and checkpoints before test scoring. Prefix, first post-ticket and full-execution views separate pre-feedback recognition from later inference. Paired Full--Projected comparisons measure the forwarding intervention; Dedicated--Shared comparisons address connection policy. Phase attribution is specified for the serial pair. Shared and Joint use complete windows and continuous detection: a task's post-ticket interval can contain other tasks' model streams, so a score for that interval would mix their exposure.

Continuous multilabel LR and random-forest detectors use validation-selected windows and thresholds. A gap-based detector and constant class-presence controls remain explicit baselines. Event scoring matches distinct task instances, including repeated classes, at overlap thresholds .3/.5/.7. Mean false events per session accompany recall; the supplement retains duration-normalized rates. Uncertainty resamples complete sessions. LR additionally refits under training/test session resampling, conditional on the selected family and designed workload. Eight primary local contrasts form one Holm family; exploratory and remote comparisons remain separately identified.
