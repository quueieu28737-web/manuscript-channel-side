\section{Conclusion}\label{sec:conclusion}
A side-channel defense result describes one observation, one execution and one attacker. Reusing it in an LLM or agent deployment is sound only when those three things still hold, and the reporting card makes that check explicit for each claim: supported, incompatible, or unresolved with a named measurement. Two cases show what is at stake. Against a clean-trained attacker, response batching looks like it reduces leakage to chance; against an attacker trained on batched outputs, it leaves nearly all of it. Cover whose response is discarded can still cost almost half of an agent's task successes when the cover writes. Whether the card helps analysts avoid such errors is the question that the next study must answer.
