\section{A Taxonomy of Evidence-Reuse Boundaries}\label{sec:corpus-map}
The taxonomy describes the change between a source result and the proposed deployment. Several boundaries can change together.
\input{tables/r33-change-taxonomy}

\paragraph{Receiving view}
The generating layer does not determine the receiver's observation. A network observer, tool provider and private-state-aware formatter can expose different projections of the same execution. An output filter's semantic authorization therefore does not by itself bound timing, length or representation choice. A source-scoped guarantee or attack score is retained only for its named released view.

\paragraph{Affected state}
A saved-trace transformation, a live framing wrapper and an admitted tool action are different interventions. Lossless framing can preserve a content projection without another content-quality benchmark. A concurrent read still uses resources; an apparently same-value write can consume stateful permissions or create accounting effects. Task completion, quotas and execution cost require their own operating point.

\paragraph{Attacker and workload}
Protection under a fixed classifier does not identify protection after defended-data fitting. Likewise, evaluating a rule on several models differs from transporting a source calibration unchanged. A workload change can affect attack training, defense parameters, quality and resource costs separately. The reporting card records what remains fixed and which object is measured again.

\paragraph{Relation to established evaluation methods}
Website fingerprinting already supplies adaptive attacks, cost trade-offs and environment-shift tests \cite{cai2014systematic,juarez2014critical,mathews2023critical}. Robustness guidance discusses attacker access and evaluated interfaces, while benchmarks standardize comparison protocols \cite{tramer2020adaptive,carlini2019evaluating,croce2021robustbench}. Adaptive testing, workload separation, observer specification and protection/cost trade-offs are inherited principles, not conceptual inventions of this paper. The application here makes LLM/agent-specific joins inspectable: prefix-policy protection versus semantic-cache processing cost, authorized message content versus an exposed score or form, and a discarded reply versus the state of an executed tool call. The external WF examples reproduce decisions already supported by their source papers. The added material is a version/locator-linked organization of these objects and bounded experiments, not evidence that the procedure finds errors missed by prior guidance or improves analyst performance. Formal DP, information-flow, constant-time and oblivious-memory results retain their stated adjacency, leakage model and runtime assumptions \cite{dwork2014foundations,smith2009qif,almeida2016constanttime,stefanov2013pathoram}; an empirical classifier score is not their substitute.
