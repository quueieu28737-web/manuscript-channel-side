\section{Case Study: Applying the Evidence-Reuse Audit}\label{app:case-study}\label{app:equivalence}
This worked application follows the SoK's procedure: fix the receiver and intervention, identify the configuration-linked outcomes, then check which deployment change the evidence covers. The four contrasts below belong to one case study. Historical study keys and complete protocols remain in Appendix~\ref{app:experiments} and the supplement.

\paragraph{Setting and measurement scope}
The transport component uses 48 saved responses on 24 topics (12 training/12 test). The agent component uses 115 public retail tasks from 53 customers: GPT-6.1 Sol/low supplies 690 repeated episodes, and served Luna, MiniMax and GLM aliases supply separately scoped extensions. The frozen retail split has 69 training/46 test tasks and 29/24 disjoint customers; test cancellation/return positives number 5/7 customers. The operation-category target identifies the requested cancellation/return action. It differs from the saved responses' verbosity target. TLS loopback captures, offline transforms, emulated WAN paths and fresh planner runs retain distinct execution/cost objects.

\paragraph{Follow the binding rather than the mechanism name}
The first contrast binds cost to the final emitter. The second distinguishes unchanged observed tool categories from state preservation. For deterministic real tools, forwarding the same real actions, executing cover on disjoint state and suppressing cover replies preserves logical real-call responses and final state; this conformance property excludes wall-clock time. It does not measure the utility of a deadline-sensitive planner. The separate 100-episode prefix-cover study observes 37/50 baseline and 33/50 defended successes (difference $-8.0$ points, customer interval $[-23.9,6.5]$), at that scheduler's scope.

\paragraph{Interpretation and reconstruction}
The application shows how to specify a missing binding before extending a result. It supplies workload-specific examples, not corpus-wide frequencies. Reused customers, mutable model aliases, unequal inference budgets and exploratory analyses limit its transfer scope. The original screen (upper 95\% BA $<0.60$ and AUROC $<0.65$ for both targets) remains unmet. S11--S26 retain full protocols and results, S30 retains corrected calibration statistics, and S31--S32 collect the detailed grids. The main SoK findings derive from the source-record audit.
