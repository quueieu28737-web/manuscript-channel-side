\section{Conclusion}\label{sec:conclusion}
This SoK organizes defense evidence around the changes a deployment introduces: a different observed signal, executed intervention or evaluation setting. The record atlas supports scoped comparisons, identifies outcomes measured at the same configuration, and turns holdout evidence into concrete measurement plans. Its practical output is visible in the cache example: retain prefix-recovery candidates for a shared threat, keep semantic-cache cost separate, and carry forward a quality/cost package only at its measured operating point.

The published record identities, query memberships and filled reporting cards make these decisions inspectable. Pair frequencies depend on the indexing rules; the scientific value lies in the source-supported distinctions and reusable decision process. Worked applications illustrate that process while preserving the scope and uncertainty of each source result.
