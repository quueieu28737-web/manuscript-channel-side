# R116 code and aggregate companion subset

This directory contains the previously public live-study implementation, frozen training pools, live aggregates, record-only analysis implementations and aggregate outputs, and unchanged historical manuscript/source archives.

Individual episodes/calls, observed record timestamps, predictions, transcripts, packet captures, TLS keys, credentials and weights are NOT included. Re-fitting historical attacks, reconstructing features, replaying individual states and exact role checks require the withheld local inputs. No release of them is promised. The complete local review/data packages are not uploaded.

Historical plans and archived documents retain their original wording, including superseded publication proposals; they do not authorize new data publication. The current distribution boundary is this README and the release index. R116 Supplement S1.4 retains a historical release sentence, noted in the author-side review; it does not enlarge this release.

- live-study/: pinned R110 public implementation, plans, training pools and checks.
- live-aggregates/: grouped attacks/tests, costs/outcomes and record-clock summaries.
- record-only/: R115/R116 aggregate analysis and original scripts; no individual vectors.
- evidence-archive/: unchanged R115 papers/source, including older source-inspection and pilot records.

The scripts preserve their original runtime/path dependencies; this is source and aggregate inspection, not a turnkey anonymous full-data reproduction. No collector, fitter, model request or new experimental plan is executed by this release.
