## 新增分析

- **表 11 容忍度判定**：示例容忍度为识别率 ≤ 60%（72/120）、goal 和 state 各自最多比 no cover 少 3/120、token ≤ 2.5×、call-window 字节 ≤ 2×。
  - 对 call-window 观察者：只有 shadow 通过，其中 Llama 的 state 恰好在限值上。
  - 对 record-only 观察者：Qwen 的 history-concurrent 通过（不增加 token），Qwen 的 shadow 以 1 个 fixture 之差不通过。
  - 正文写明了两个敏感性：state 容忍度收紧到 2/120 时，Llama 所有策略都不通过；识别率放宽到 65% 时，record-only 观察者下 Qwen 的 sequential 和 shadow 都通过。
  - 正文也明确说明：这些容忍度是看到结果之后设定的，只用来演示协议，不构成验证。
- **图 3 成本前沿**：8 个实测点，加上 iid 和 distinct 两条理论下限曲线，以及 60% 容忍度线。
