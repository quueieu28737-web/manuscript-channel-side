# R107 后续实验：先识别调度指纹，再比较调度与执行位置

原方案固定在上游提交 `6c832f068a7fb2dfc38feb1bde37c38252250bd5` 的
`releases/r107/EXPERIMENT-PLANS.md`。该文件和上游稿件保持原样。本文件是结合
代码审查与 B1 后形成的修订设计。B1 的可执行规则另由 `analysis-plan.json`
及 `freeze.json` 绑定；A、B2 的正式采集计划尚未冻结或启动。

## 1. 当前完成范围与决策

B1 已使用原 M3 的 3,600 个回合完成离线拟合，测试部分为 1,440 个回合。
旧尺寸/目的地 LR、RF 的全部 held-out 预测精确复现。新增计时测试前的冻结
时刻见 `freeze.json`；技术复算见 `verification.json`。

计时先识别诱饵、再剥离的攻击，将 Qwen 五个 cover 条件的正确数从 61–63/120
提高至 111–114/120，将 Llama 从 72–82/120 提高至 107–115/120。
这组事先列明的次级比较全部通过各自十项 Holm 校正。单纯拼接计时特征的主比较
没有改善，完整结果在 `RESULTS.md`，两组结果均保留。

因此，新调度首先要与计时剥离攻击交手。单独修补最后一个目的地，不能支撑
对具备计时观察能力的攻击者的隐私收益。A 保留原尺寸/目的地视角的可比性，
同时必须报告同一回合上的计时剥离攻击。B2 再用中继的 TLS 记录时间戳验证
客户端回执观察能否迁移到实际链路记录。

- 对比在同一组新 fixture 上配对；跨 arm 共享 cover 动作、对象及随机带。
  调度不使用待预测任务标签、未来执行长度或测试分数。选取诱饵时不得通过
  排除真实动作来人为添加类别约束；使用预先固定的公开训练边际分布。
- 每个 arm 的任务、全局状态、额外配额、模型/工具调用、字节与耗时来自同一批

- 先检查依赖和冻结权重身份，再用独立开发 fixture 检查新增路径。正式数据的

- 新采集器必须接收自己的输出根目录、端口与计划；不能直接导入旧 `collect.py`
  后调用其主入口，因为其模块级 `H`、`PLAN`、端口和日志路径绑定旧实验。
  业务状态函数和特征接口可以复用，新增采集器单独冻结源码及参数。

## A. 调度覆盖与执行语义

### A.1 把因子设计补齐，并匹配 cover 数量

原八臂缺少 early-isolated，而且“前段 1–2 个”与“全程 4 个”同时改变了
位置和数量。保留原八臂的全部用途时，需要再增加两个**同为四个 cover**的
前段 arm，才得到位置覆盖 × 执行位置的完整 2×2。

| Arm | 调度 | 语义 | 用途 |
|---|---|---|---|
| A0 | 无 cover | 无 | 同批次基线 |
| A1 | 原 M3 前段 1–2 个 | disposable proxy | 原调度复测 |
| A2 | 尾部 1–2 个 | disposable proxy | 与 A1 匹配数量，测试位置 |
| A3 | 随机公共插槽，2 个 | disposable proxy | 小预算点 |
| A4 | 前缀 1、尾部 1、两个随机公共插槽，共 4 个 | disposable proxy | 全程覆盖因子单元格 |
| A5 | 补到公开调用数 L | disposable proxy | 调用数归一化基线 |
| A6 | 与 A4 相同 | persistent isolated | 全程覆盖因子单元格 |
| A7 | 与 A4 相同 | live write | 明确的对抗性状态压力测试 |
| A8 | 首次取票后、首次模型决策前 4 个 | persistent isolated | 前段因子单元格 |
| A9 | 与 A8 相同 | disposable proxy | 前段因子单元格 |

因子对比为 `{A9,A8} × {A4,A6}`：固定 cover 预算，改变调度与执行位置。
A7 不进入二水平语义因子；其状态损害是另一个构造性对照。若必须维持八臂预算，
需要明确删去两个辅助调度臂；不能保留原八臂并把缺失的单元格说成已测量。

### A.2 可在线实施的调度定义

LLM 的最终调用数未知，所以“在全部实际位置上严格均匀抽样”需要未来信息。
新调度采用公共最大步数上的随机插槽，不读取基线的最终调用数：

1. A4/A6/A7 预留一个取票后的前缀 cover 和一个终止前的尾部 cover。
2. 其余两个 cover 的插槽在公共步数上抽样，并在所有语义条件间固定。
3. 对已取得终态的提前结束、功能失败或步数上限，将未到达的插槽在终止前发送。
   报告这种尾部回填的次数和实际位置分布；不称其为对实际轨迹位置严格均匀。
4. 尾部触发点为规划器已选择 finish/已有功能终态、但尚未发布 episode 终态。
   发送结束后再计算业务结果和关闭窗口。未返回请求的 unknown 不触发补发逻辑。
5. 对每个 cover 增加计时匹配的版本：等待从旧训练划分提取、按模型固定的
   honest 间隔抽样。连发的第二个 cover 也必须等待。旧训练分布不是新部署的保证。

在相同采集上报告 timing-free 与 client-timing 两种观察者；如果预算只允许一个
计时策略，主因子四格统一使用计时匹配，A1 另保留原立即派发调度。这样不会把
“是否补等待”与“是否真实执行”混为一个因素。

A5 只补齐调用数。把随机目的地追加到原序列，仍保留原序列这个有信息的子序列，
因此不能称为类别无关的完整轨迹或隐私上界。L 用训练决定，超过 L 的执行继续，
单独报告溢出。若要实现完整轨迹归一化，需要独立设计固定的公共服务轮转，
等待对应服务插槽再执行诚实请求；那属于另一种成本更高的调度，不在这里偷换实现。

### A.3 攻击与主要指标

固定套件包含原 LR/RF、冻结无 cover 攻击、末/倒数第二目的地规则、目的地 n-gram
及调度感知模型，以及 B1 的检测—剥离攻击。四个因子单元格的主算法按各格
validation 平均表现统一选择，再分别拟合各格数据；同时保留每个攻击的结果。
所有选择在新测试数据评分前完成。

“所有攻击的测试最大值”作为固定套件的描述性最强已测结果报告。它不能直接
替换成一个事后选定攻击，再套普通 McNemar 或 TOST。真正的 paired 主检验使用
事先固定、validation 选择的预测器。披露 cover 真值后剥离的攻击是**特权参考**；
一个分类器在特权视角下的分数不是 Bayes 隐私上界。

### A.4 对比与等价性

- 位置：A2−A1（相同 1–2 个预算）以及 A4−A9（相同四个预算）。
- 语义：A6−A4、A8−A9。
- 交互：`(A6−A4)−(A8−A9)`，在每个 fixture 上构造差值后分析；不能直接将
  四臂交互当成一个二元 McNemar 表。
- A3/A5 的预算/调用数补齐效应与 A7 的状态压力另列次级族，不混入上述因子。
- 区分识别、任务、状态和成本终点，跨模型的同类确认性比较预先固定 Holm 族。
  区间保持配对 fixture，并说明固定攻击者或包含重新拟合的范围。

±8 pp 的 TOST 限于 **A6 与 A4 的主攻击准确率差**。它不证明两种程序的语义等价、
整个信道相等，也不证明任务和状态等价。两模型各自报告，等价 p 值取两项单侧
检验的最大值，再对两模型控制家族错误。非显著差异不能代替 TOST 通过。
训练选择后预测器固定时，可用配对正确性差的 TOST；实现采用配对 t 近似，
并通过预先规定的配对二元分布模拟评估覆盖与功效，不称为精确有限样本检验。

`plan_power.py` 以假定不一致率 q 做规划，没有用新的 held-out 计时结果选样本数。
真差异为零、q=.30 时，未校正单模型 80% 等价功效的近似量为 402 对；用 .025
作两模型家族的保守单项阈值约需 493 对。100,000 次模拟下，120 对的功效仅
约 .026%，240 对约 23.1%，504 对约 81.2%（这些是该假定分布下的单项功效）。
若要两个模型同时有约 80% 的联合成功机会，还需更高单项功效；612 对的模拟
单项功效约 90.1%。不能把“240 对”直接写成有充分功效。

| 假定配对不一致率 q | 真差异 0，±8 pp，alpha=.025，80% 单项功效近似对数 |
|---|---:|
| .05 | 83 |
| .10 | 165 |
| .20 | 329 |
| .30 | 493 |

正式预算需在新 train/validation 后、test 前根据预先固定的方差规划规则决定，
并设置资源上限；若上限不足，就接受等价结论可能不确定。十臂每格300个
fixture 的基础设计为 **6,000 episode**，已经超过原4,800估计。增加确认性
测试对数还会继续增加成本。墙钟时间需用新开发运行和实际调用数估算。

## B1. 已完成：回执计时的离线分析

冻结规则见 `analysis-plan.json`。关键实现包括：

- 完全复用原153维特征与原 LR/RF；T1 为202维（增加49维计时），T2 只有49维。
- 每个模型汇集训练划分的各 arm，学习逐调用 cover 检测器；validation 决定
  LR/RF、阈值或间隔规则。该攻击者拥有带 cover 标签的训练/验证轨迹；test
  推断只使用时间、目的地和可见边界。第一条取票调用按公开控制器规则保留。
- 删除预测的 cover，再用无 cover 数据训练、validation 选出的原分类器识别。
  普通剥离攻击没有使用测试 cover 真值；真值只用于评分及特权参考。
- 主族为 T1−原尺寸攻击（十项），检测—剥离为事先固定的次级族（十项），
  隐藏语义两两比较为另一个次级族（十二项）。不把有利次级结果改称主结果。

原 M3 的测试尺寸分数和执行结果早已公开。本轮在**新的计时 test 特征和评分**前
冻结，属于回顾性的扩展观察者分析，不能称为全新、从未接触过的确认性样本。
回执开始/结束还含客户端调度和计数等待；模型使用记录及内容没有进入攻击。

## B2. 新采集：实际 TLS 记录计时与延迟仿真

### B2.1 保持可识别的五个条件

所有有 cover 的条件使用同一已冻结的全程四个 cover 规则、动作、对象和随机带。

| Arm | 派发等待 | cover 响应路径 |
|---|---|---|
| B0 | 无 cover | 原诚实执行 |
| B1 | 立即派发 | proxy 固定协议响应，无业务执行 |
| B2 | 匹配 honest 间隔 | 同 B1 |
| B3 | 匹配 honest 间隔 | proxy 固定协议响应＋冻结的延迟仿真 |
| B4 | 匹配 honest 间隔 | 在隔离状态上真实执行并经历服务延迟 |

原 M3 的 `transport_drop` 也在 disposable copy 上运行 `dispatch`，所以不能只
改名字便把它当成 B1/B2/B3 的“无业务执行”。新 proxy 路径必须在业务函数前
终止，生成预先指定、最终按相同方式编码填充的隐藏响应；服务器回执记录
业务函数是否进入、是否访问隔离状态、是否产生下游调用，供验证器检查。

### B2.2 延迟和时钟

读/写延迟用冻结的 lognormal 画像（候选中位40/150 ms，log标准差.35）；
这是合成画像，开发阶段可确认实现是否达到配置，参数必须在正式采集前确定。
每个 cover 的随机延迟按 fixture/cover ID 固定并在 B3/B4 共用，禁止按真实任务
类别或测试攻击分数调参。真实执行仍会有额外 CPU、协议及调度开销，另行记录。

派发等待从**旧训练** honest 调用间隔提取，排除首个取票调用；按模型抽样，
按目的地分层必须满足预先固定的最小训练数，否则回退到全局分布。每次 cover
都单独等待，不能只延迟同一批的第一个。报告新执行中实际达到的分布。

中继在读取加密字节时用 `time.monotonic_ns()` 记录首/末字节到达，增量解析
TLS 记录并保存方向、长度和首/末字节时间。一个 TCP read 含多个记录时，
共享读取时间是实现分辨率限制，不得伪造更精细时间。分片记录、握手、重连、
计时开销和日志丢失均有完整性检查。单调时间与墙钟只在运行开始记录映射。

### B2.3 观察者、对比和效力

主观察者使用中继实际记录的 TLS 长度、方向、目的地/连接标识及时间。
主特征不能读取客户端 `tool_receipts`、模型 token 或业务回执。提供 episode
边界的记录序列识别与提供逐调用边界的诊断检测分开报告；HTTP/2 不自动向
被动观察者暴露调用窗口或解密后的 stream ID。并行 worker 的连接归属权限
必须在采集计划中固定，不能在分析时借用 evaluator 私有映射。

三个预设问题为 B2−B3（服务延迟是否还能识破）、B3−B4（延迟仿真与隔离
执行的固定攻击准确率是否在±8 pp内等价）、B4−B1（整体组合效应）。同时
报告 B1 的检测—剥离攻击、固定套件内最强已测结果及完整效用/成本。
TOST 的预算与多重比较使用 A 中的原则，不能从 A 或旧 B1 的点估计宣布通过。

B3/B4 若通过等价检验，只能说明：在所实现的服务画像、链路视角、工作负载
与攻击套件上，两者的识别率差被限制在预定区间。不能从这个结果推出真实
执行在所有观察者面前都可由 sleep 替代。看得到下游访问、缓存争用或模型
链路的观察者可能有另外的可见量；当前实验不替这些视角做结论。

按每格300个fixture，B2为3,000 episode，但这仅是采集数量，不保证±8 pp的
等价检验功效。正式启动前还需完成实际记录采集器、pure proxy 分支、延迟
一致性验证和样本量选择，再冻结代码/计划。当前未运行 B2。

## 3. 论文将使用的结论强度

B1 已支持的具体结论是：**当前控制器的快速插入调度留下了可检测的回执时间
指纹；利用该指纹剥离诱饵后，固定无 cover 分类器恢复了较高的任务识别率。**
这是该实现和观察条件上的绕过，不是所有 Agent cover 的普遍失效。

A/B2 将回答哪种调度、仿真与隔离组合能在预定观察权限下形成较好的工作点。
在取得数据前，不写“调度决定隐私、语义只决定状态”或“语义已经等价”。
结果最终按实际调度、可见量、攻击者、效用与成本共同解释。

统计方法接口参考：[paired TOST](https://www.statsmodels.org/stable/generated/statsmodels.stats.weightstats.ttost_paired.html)，
[exact binomial tail used for paired McNemar](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html)。
