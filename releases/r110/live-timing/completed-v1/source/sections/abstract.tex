\begin{abstract}
Encrypted Agent communication exposes tasks through model, tool and Web services. We systematize fifteen Agent studies, comprising forty-four settings, against twenty-two established traffic-analysis anchors. Two execution boundaries organize the evidence. Tool results can enter later model requests, so protection scope follows the services an observer can access. Cover can execute application work, so privacy and business outcomes must be measured under the same intervention; none of four mapped query/workflow privacy settings documents both an adapted attacker and matched utility. We apply the resulting procedure to executed cover with two fixed-weight LLM planners over MCP, TLS~1.3 and HTTP/2. In 3,000 episodes, removal without cover labels restores recognition from 75/120 and 80/120 to 112/120 and 108/120. Live historical-gap dispatch defeats that simple rule but leaves adapted context and joint-decoding attacks: concurrent dispatch gives gains of 27.5 and 31.7 percentage points after Holm correction. With planner-generated shadows, validation selects a size-only attack; model tokens approximately double and substantial task inference remains. The SoK contributes access-aware attack and defense maps, a classical-to-Agent transfer matrix, and an evaluation procedure linking residual inference to task, state and resource outcomes.
\end{abstract}
