# TLS-record 计时与影子规划器：已完成结果

完成 3,000 个正式主回合（另含 600 条影子执行链）。每模型、每臂 300 个夹具：120 训练、60 验证、120 测试。原有 M3 夹具和措辞复用，两个本地固定权重模型；没有分析师实验或新增文献检索。

## 三个问题的答案

1. **无 cover 标签的剥离在 TLS record 时钟下仍成立。** Qwen 从 75/120 恢复到 112/120，Llama 从 80/120 恢复到 108/120；两项均满足预定复现规则并通过 Holm。这里无标签指不需要 cover 角色标签，任务分类器仍使用训练任务标签。独立抓包时钟复算给出相同结果。
2. **真实历史等待没有消除适应性攻击优势，离线反事实不能代替实测。** 顺序派发的增益为 14.2pp（Qwen，Holm p=.0559，未过 .05）和 18.3pp（Llama，p=.0007805）。并发派发分别为 27.5pp 和 31.7pp，均通过 Holm。最低 hold 不是实现后的相同分布：Qwen 40.5ms 平均抽样时长在顺序/并发下实际为 100.4/171.2ms。上下文攻击同时使用目的地、位置和尺寸，增益不能单独归因到时间。
3. **影子方案改变了本套攻击的选择，但没有证明诱饵不可区分。** 两模型的验证选择都退回尺寸攻击，因此 E 家族的零增量等价结论对这两个相同预测器是平凡的。预先规定的 RF 在测试上仍为 70/120 和 64/120；链分离攻击为 49/120 和 34/120。模型 token 为 2.01×/1.99×，call-window 字节为 1.68×/1.71×。

## 验证与范围

固定模型层前后哈希、全部请求终态、业务状态重放、历史池成员和派发锚点通过核验；773,450 条 TLS record 与独立 TCP 重组一致，未知为零。去载荷包精确复现了冻结的攻击、选择、配对统计、条件区间和成本，另复现八格 packet-clock GMM。
观察者有任务和调用窗口及目的地；不看模型链路。相同服务的调用串行，不是无限制的共享 HTTP/2 多路复用。记录读完成是软件时间戳；call-window 端点误差最大约 148ms，未作物理信道保密证明。区间条件于已拟合攻击和既有夹具。
论文保持 Agent 通信侧信道 SoK 主线，15 来源、44 设置和原真实／阴性结果保留。新的五臂结果整合于主稿 §7.1 和补充 S12，旧回执反事实仍独立保留。
