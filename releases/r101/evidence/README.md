# Evidence subset for R101

The field map retains 44 settings from 15 direct sources. The transfer synthesis
adds six condition correspondences and an evidence-availability ledger derived
from those existing records. Source versions and passage locators are preserved.
Counts describe what was located in the retained records; they are not paper
quality scores or estimates of field-wide prevalence.

From the release directory, run:

    python evidence/verify_evidence.py

The checker verifies the publication manifest, each row's original basis, the
access/purpose partitions and the four-setting privacy denominator. It does not
reproduce source experiments or certify semantic interpretations. The complete
local review archive includes the experimental inputs and historical studies;
it is separate from this small public manuscript/evidence export.
