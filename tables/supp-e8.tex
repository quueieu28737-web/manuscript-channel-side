\section{Autonomous-agent pipeline (E8) and online cover}\label{app:e8}
\path{experiments/sp2027-r2/agent/} runs tool-calling agents and a user simulator on the 115 retail tasks, applies \emph{online} cover (decided before each real call from the history only, with a final flush) and replays every session over TLS. Because sandboxed cover and framing never reach the agent, one trajectory per task and seed serves all policies. No LLM was available for this revision; the rows below use stand-in planners and validate the pipeline. The scripted planner replays reference programs (native reward 1.00); the noisy planner inserts extra reads before each reference call with probability 0.3 (7.2 versus 5.1 real calls per session). These are synthetic results, not agent measurements.
